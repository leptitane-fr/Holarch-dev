Une page d'essai

Encart flottant. Le texte de l'article passe à côté de lui, puis reprend toute la largeur en dessous.

Ce moteur est écrit de zéro, en Rust, sans aucune bibliothèque : il lit le HTML, applique le CSS (la cascade, var(), calc(), les sélecteurs), place les blocs et les lignes, puis dessine la page avec les polices Manrope et JetBrains Mono. Les mots gras, italiques, soulignés, barrés et les liens suivent le texte d'une ligne à l'autre.
